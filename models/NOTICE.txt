models/ 폴더의 모델 파일

face_detection_full_range.onnx  — MediaPipe Face Detection (full range, BlazeFace)
face_landmark.onnx              — MediaPipe Face Mesh (468 랜드마크)

- 원 모델: Google MediaPipe, Apache License 2.0 (https://github.com/google-ai-edge/mediapipe)
- 받은 곳: PyPI 패키지 face-detection-tflite 0.6.0 (MIT, Patrick Levin) 에 들어 있는 .tflite
- 변환: tf2onnx 1.17 (opset 13), 구조·가중치 변경 없음
- 상업 사용: Apache 2.0 은 상업 사용·재배포 허용(이 고지 유지 조건)

mtcnn_pnet/rnet/onet.onnx       — MTCNN (작은 얼굴). PyPI mtcnn 1.0.0 (MIT, Iván de Paz Centeno) 가중치를 tf2onnx 로 변환
                                  원 학습 데이터: WIDER FACE · CelebA (비상업 연구용) → 이 모델은 비상업 용도로만 사용
nanodet_m.onnx                  — NanoDet-m (사람 검출, COCO). npm @vladmandic/human-models 3.0.4 (MIT) 의 TFJS 를 tf2onnx 로 변환
                                  원 모델: RangiLyu/nanodet (Apache 2.0)

text_det_ppocrv4.onnx           — PP-OCRv4 글자 검출(DB, 위치만·글자 읽기 없음). PaddleOCR (Apache 2.0, https://github.com/PaddlePaddle/PaddleOCR)
                                  받은 곳: PyPI rapidocr-onnxruntime 1.3.24 (Apache 2.0) 의 ch_PP-OCRv4_det_infer.onnx, 변경 없음
