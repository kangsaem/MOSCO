# MOSCO

한 번에 여러 클립을 장면 인식해 자동 보정하는 **AUTO**, 작은 얼굴·몸 기반 머리 찾기, 타원 수정(키프레임), GPU(DirectML) 검출을 지원합니다.

방송용 얼굴 처리 도구 (Windows, 설치 없이 폴더째 실행)

- **뷰티**: 1인 인터뷰. 얼굴을 찾아 머리 전체에 넉넉한 타원 → 그 안의 피부만 매끄럽게(주름·잡티 완화). 눈·눈썹·입은 제외
- **블러**: 시장 같은 군중. 모든 얼굴을 찾아 사람마다 따라가며 페더 타원 블러/모자이크
- 출력: **ProRes 422 HQ**(.mov, 10bit 4:2:2, 원본 오디오 PCM·타임코드 유지) / 블러는 **ProRes 4444 알파 오버레이** 추가 / 검수 영상(H.264, 타원·ID 표시) 선택

## 받기 · 실행

1. GitHub 저장소 → **Actions** → 최신 "Windows build" → 아래 **Artifacts** 의 `MOSCO-windows` 다운로드
2. 압축을 풀고 `MOSCO.exe` 실행 (C:\Program Files 처럼 쓰기 제한된 폴더는 피하기)

폴더 안: `MOSCO.exe`, `bin/ffmpeg.exe·ffprobe.exe`, `models/`(얼굴 모델), `cache/`(분석 결과, 지워도 다시 만들어짐), `presets/`, `settings.json`

블러 값: [블러 \| 모자이크] · 강도 / 타원 여유 · 페더 · 떨림 보정 / 민감도 · 최소 크기 · 놓침 유지 · 다시 잇기 · [몸으로 머리 찾기]

타원 편집(공통): 모니터에서 타원 클릭 = 선택, 끌기 = 위치, 흰 손잡이 = 크기 → 그 프레임에 키(◆).
자동 타원의 키는 고친 만큼만 앞뒤로 부드럽게 더함(나머지는 계속 자동으로 따라감).
[타원 추가](A) → 모니터 클릭 · [합치기] → 다른 프레임의 같은 사람 타원 클릭 · [키 삭제] · [끄기 ▾] · 타원별 크기·페더·강도.
소스 바의 ◆ 클릭 = 그 프레임으로, 우클릭 = 키 삭제.

숫자를 클릭하면 직접 입력(Enter 적용, Esc 취소).

**AE 보내기**(렌더 목록 위 [AE]): 현재 소스의 타원·간판 사각형(수정 반영)을 에펙 마스크 키프레임 스크립트(.jsx)로 저장. 렌더 안 함.
에펙에서 소스 레이어를 선택 → 파일 › 스크립트 › 스크립트 파일 실행 → 레이어가 복제되고 마스크(ID별 이름, 제외 타원 = 빼기)와 키가 생김.
키는 오차 1.5px 넘는 곳에만(편집하기 쉽게), 나타남/사라짐은 마스크 불투명도 고정 키. 블러·간판은 가우시안 블러(또는 모자이크) 효과까지(세기는 근사값), 뷰티는 마스크만.
구버전 에펙(CS6 무렵)부터 동작하도록 만듦. 레이어 시간 늘이기(stretch)는 100% 기준.

## 처리 방식(요약)

- **불러올 때는 분석하지 않음**(가벼움). 멈춤 상태에서는 보는 프레임만 그때그때 보정해서 보여줌
- 스크럽·미리보기는 **상주 디코더(PyAV)** 로 프레임을 읽어 빠름(파일마다 ffmpeg 를 새로 안 띄움). ProRes 한 프레임 약 8ms
- 재생은 원본을 보기 화질로 바로 재생(보정 없음). 움직이는 보정 결과는 [분석] 후 또는 렌더로 확인
- [분석]을 누르거나 렌더하면 그때 전체 분석(얼굴·트래킹) → `cache/analysis` 에 저장. 슬라이더는 분석 결과의 후처리라 바로 반영
- 블러: 화면 전체 + 겹치는 타일(작은 얼굴용)로 검출 → 사람별 추적(ID) → 놓친 구간은 앞뒤로 메움(놓침 유지 프레임까지, 앞뒤 2회)
- 렌더는 타원 영역만 처리하고 나머지 픽셀은 원본 그대로 통과

## GPU 가속

렌더 설정(⚙) → 검출 장치 → GPU 를 고르면 얼굴·사람 검출을 GPU(DirectML, 윈도우 내장 DirectX12)로 돌립니다. 분석·AUTO 가 빨라집니다. ProRes 인코딩 자체는 CPU 입니다(NVENC 는 ProRes 미지원). 쓸 수 있는 GPU 가 없으면 자동으로 CPU.
